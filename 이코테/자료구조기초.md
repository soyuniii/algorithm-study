### 탐색
많은 양의 데이터 중 원하는 데이터를 찾는 과정 
-> DFS, BFS

### 자료구조
데이터를 표현,관리,처리하기 위한 구조
-> 스택, 큐 (삽입/삭제)

**오버플로**
데이터 크기가 가득 찬 상태에서 삽입연산

**언더플로**
데이터 없는 상태에서 삭제연산

### 스택
선입후출/후입선출 구조
```python
stack = []

stack.append(5)
stack.append(2)
stack.append(3)
stack.append(7)
stack.pop()
stack.append(1)
stack.append(4)
stack.pop()

print(stack) #최하단
print(stack[::-1]) #최상단
```

### 큐
선입선출 구조
```python
from collections import deque

queue=deque()

deque.append(5)
deque.append(2)
deque.append(3)
deque.append(7)
deque.popleft()
deque.append(1)
deque.append(4)
deque.popleft()

print(queue) # 먼저
queue.reverse()
print(queue) # 나중
```

### 재귀 함수
자기 자신을 다시 호출하는 함수
```python
def recursive_func():
    print('재귀함수 호출')
    recursive_func()

recursive_func()
```
**종료조건**을 명시해줄것!
```python
def recursive_func(i):
    if i == 100:
        return
    recursive_func(i+1)
    print(i,"번쨰 재귀함수 종료")

recursive_func()
```
재귀함수는 내부적으로 스택 자료구조와 동일..

**팩토리얼**예제
- 반복 구현
```python
def factorial(n):
    result = 1
    for i in range(1,n+1):
        result *= i
    return result
```
- 재귀 구현
```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n-1)
```

### DFS 
-> 스택, 재귀함수
먼 노드부터 탐색

**인접행렬**
```python
INF = 9999999
graph = [
    [0,7,5],
    [7,0,INF],
    [5,INF,0]
]
print(graph)
```
인접 행렬은 모든 관계 저장 -> 메모리 낭비/빠름

**인접리스트**
```python
graph = [[] for _in range(3)]

graph[0].append((1,7))
graph[0].append((2,5))
graph[1].append((0,7))
graph[2].append((0,5))

print(graph)
```
인접리스트는 연결된 정보만 저장-> 메모리 효율적/느림
